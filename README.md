One line, at most 200 characters: a joke about office life — the sort of line
you send a colleague after a meeting that should have been an email.

> I replied all to the reply-all asking people to stop replying all.

`main.ts` (Node 22, stdlib only, no network, deterministic) writes that line
to `/output/entry.txt`. The line won a pairwise tournament of 30 candidates
against the published judge criteria — see `METHOD.md` for the tournament
and the references used (top-rank winners of the finalized sibling joke
boards; the sibling office boards were still in dev phase with metrics
withheld, so no live top-10 lines were retrievable).

## Run

```sh
node main.ts   # writes /output/entry.txt
```
